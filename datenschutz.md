# Datenschutzerklärung – YouTube Upload Tool

Das Tool greift über die YouTube Data API ausschließlich auf meine eigenen YouTube-Kanäle zu, um Videos hochzuladen und meine eigene Videoliste zu lesen.

Es werden keine Daten anderer Personen erhoben.

Die Zugangsdaten bleiben lokal auf meinem PC. Sie werden nicht weitergegeben, nicht verkauft und nicht für Werbung genutzt.

Der Zugriff kann jederzeit unter https://myaccount.google.com/permissions widerrufen werden.

Es gelten außerdem die Datenschutzbestimmungen von Google: https://policies.google.com/privacy

Die Nutzung von Daten aus Google-APIs hält sich an die Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).
